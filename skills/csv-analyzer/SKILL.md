# csv-analyzer

Analyzes CSV files to extract insights, generate charts, and clean data.

## Capabilities

- Parse and summarize CSV data
- Generate bar charts, line graphs, and other visualizations
- Clean data by handling missing values, duplicates, and type mismatches
- Filter, sort, and transform columns
- Export cleaned or processed data to new CSV files

## When to use

Use this skill when the user asks to process, visualize, or clean CSV data. Trigger keywords include: CSV, spreadsheet, data analysis, chart, plot, clean, filter, parse.
